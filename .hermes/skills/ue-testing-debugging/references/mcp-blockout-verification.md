# MCP blockout verification (UE 5.8)

- For reference-image infill, select actual roof centers and calibrate their placement against existing landmark/perimeter anchors. A perspective drawing needs a piecewise mapping, not a single metres-per-pixel conversion. Preserve occupied user footprints, keep landmark courtyards and streets clear, and report adapted relative placement rather than claiming a pixel-perfect recreation.
- Refresh the live actor audit on each turn: the user may have moved or added blocks since the previous saved plan. Check every planned footprint against current bounds and the ground extent, then verify original transforms and tracked-file hashes after editing.
- Return a dictionary from the restricted ProgrammaticToolset script's run() function; wrap lists under a named key, or the tool rejects otherwise successful read-only batches.
- Discover toolsets and read the exact input schemas before scripting creation or capture. Use ProgrammaticToolset.execute_tool_script for batches; call only registered execute_tool functions in its restricted environment, and persist batch results in scratch to recover partial work.
- Audit existing actor transforms, labels, folders and bounds before placing geometry. Back up the saved map outside the repo and keep existing brushes and gameplay untouched. SceneTools.get_folders derives folders from actors, so empty user-created folders may be absent; inspect the Outliner with SlateInspector Snapshot instead of concluding they do not exist.
- For primitive-only buildings, use one actor with named StaticMeshComponents per landmark and subfolders beneath the requested parent. Set dimensions, relative transforms and mobility explicitly. Verify actor location after adding components and read back every part's mesh, scale, pose, visibility and collision. The Engine Cube mesh is 100 cm per axis.
- Verify collision with SceneTools.trace_world. It returns distance to the first hit, not a hit object; compare against expected surface height. Check open courtyards as well as solid buildings. This does not replace a PIE walking or navigation test.
- For CaptureViewport, pass captureTransform, annotations and bShowUI explicitly when omitted optional arguments trigger an MCP default-value error. The annotations struct requires gridSpacing, gridExtent, gridHeight, maxLabelDistance, classFilter (soft class reference) and maxLabels. Use zero spacing/distance/labels to disable overlays. Decode returnValue.image.data as base64 and inspect it. Do not flatten annotations into call arguments.
- Check available memory before starting a second Unreal process. Under heavy memory pressure, verify live geometry, save and read back the dirty flag, inspect the serialized package, and report that independent reload/PIE was not tested. Do not discard the user's undo history or unsaved work to force a reload.
- Do not require every numbered component name to appear literally in package bytes: Unreal FNames store numeric suffixes separately. Package-byte checks can verify actor labels and FName bases but cannot substitute for a full independent load.
- Compare protected file hashes and Git status after saving. Report what changed, what was verified and the remaining limitations; never commit or push unless asked.
- If skill_manage cannot resolve a project-local skill that skill_view can read, edit only its confirmed project path with patch/write_file. Do not create a global duplicate as a workaround.
